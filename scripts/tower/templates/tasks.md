# Tasks · one row = one session

> The only session-level task list. A row = one-sentence deliverable + done criteria + landing file + estimate + `config:`.
> Start: move the row to "In progress" and fill the session id. Close (`/task-close`): land the records, move the row to "Done" (date + landing file; keep 14 days, then delete), update the MEMORY line.
> Before adding a row, check the current highest number; parallel sessions appending blind collide on numbers.
> A row that can go straight to a new session gets a start card in "Ready to start"; the card is deleted when the row is done (a stale card gets pasted as if current).
