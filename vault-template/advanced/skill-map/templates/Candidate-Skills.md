# Candidate Skills — Encountered but Not Installed

Registry of skills you evaluated but did not install. A SKIP verdict is information, not
disposal: record what the skill does, why you skipped it, and the **flip condition** that would
change the verdict. Check this file before hunting for new skills — a past SKIP whose flip
condition has come true beats a fresh search. Maintained manually (the skill-map generator
never touches it).
