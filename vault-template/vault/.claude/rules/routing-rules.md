# Information Routing Rules

When the user shares information, classify and route it:

## Time-bound events → Daily Notes
- What they did today
- Meetings, conversations
- Daily thoughts and learnings
- File: `Daily/YYYY-MM-DD.md`

## Project updates → Project folder
- Progress, milestones, decisions
- Key takeaways worth remembering
- File: `Projects/Research/<name>/README.md` or `Projects/Practical/<name>/README.md`

## People → Person file
- New person mentioned, role, affiliation
- File: `People/Full Name.md`

## Plans → Plans folder
- Strategies, goals, schedules
- File: `Plans/Plan Name.md`

## Tools & workflows → Tools folder
- Reusable workflows, Claude Code setups, tool configurations
- Anything the user says they use regularly or will reuse across projects
- File: `Tools/Tool-Name.md`

## Personal achievements → Profile
- Skills, CV-worthy items, publications
- File: `Profile/About.md` or `Profile/CV.md`

## Persistent facts → Appropriate permanent location
- Durable facts (file paths, preferences, tools) go to Profile, CLAUDE.md, or Claude Code memory
- NOT to Daily Notes
